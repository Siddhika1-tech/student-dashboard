# Student Dashboard

An interactive student dashboard built using **HTML5**, **CSS3**, and **JavaScript**. The application demonstrates core front-end development concepts through multiple interactive modules, including profile management, age calculation, personalized greetings, a basic calculator, and motivational quotes.

## Features

- Student profile management
- JSON profile viewer
- Age and eligibility checker
- Time-based personalized greetings
- Basic calculator
- Random motivational quote generator
- Tab-based navigation
- Form validation and error handling
- Dynamic DOM manipulation

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Getting Started

1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Explore each module using the navigation tabs.
